FIVESTAR / SETUP GUIDE

From source code
to your first clip.

Install the tools, prepare the project, and check that your computer is ready to run Fivestar locally.

1. Install the essentials

  • Node.js 22.12 or newer, including npm. The project’s .nvmrc selects Node 22; with nvm installed, run nvm install && nvm use.
  • Python 3 with pip and venv support, used to install the stream downloader.
  • FFmpeg, including ffmpeg and ffprobe, available on your PATH.
  • A modern browser and an internet connection for dependencies, setup downloads, and online streams.

macOS

With Homebrew already installed:

brew install node@22 python ffmpeg

Follow Homebrew’s PATH instructions for Node 22, then reopen your terminal.

Windows / Linux

Windows: install Node.js and Python, then follow the FFmpeg download instructions and add its bin folder to PATH. Use WSL2 for the app’s POSIX shell commands.

Ubuntu / Debian / WSL:

sudo apt update
sudo apt install python3 python3-venv python3-pip ffmpeg

Install Node.js 22.12+ separately; the distribution’s default Node package may be older.

2. Prepare the project

Open a terminal in the extracted project folder containing package.json. Run:

npm ci
npm run setup

Setup installs yt-dlp in .tools/venv, downloads caption fonts, and prepares starter sounds and stickers. It is safe to rerun.

No accounts, API keys, environment files, or subscription setup are needed. Preferences are saved locally in data/settings.json.

3. Check your installation

Start the checker from the project folder, even before installing app dependencies:

node dist/setup-guide.mjs

Open http://127.0.0.1:5180, then press the button. Checks inspect this computer; they do not install anything.

Installation has not been checked.

4. Run locally

Once checks pass, open another terminal in the project folder:

npm start

This starts the prebuilt app; no source code or build tools are needed. Open http://localhost:5177. Leave the terminal running; press Ctrl+C to stop.

The prebuilt backend serves the browser app and API together on port 5177. No separate frontend server or build command is needed.

If something needs fixing

  • Command not found: install the named tool, check PATH, and restart the terminal and checker.
  • Missing packages or assets: rerun npm ci and npm run setup, then check again.
  • Stream links stopped working: run npm run setup -- --update to refresh yt-dlp.
  • Port already in use: stop the previous process. To move the guide, use SETUP_GUIDE_PORT=5181 node dist/setup-guide.mjs in a POSIX shell and open the printed URL.

For features and advanced configuration, read README.md in the project folder.

Everything runs on your computer. The first use of some AI features may download additional models.
